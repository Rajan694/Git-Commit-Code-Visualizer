# Change Log

All notable changes to the "Where Was I?" extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses [Semantic Versioning](https://semver.org/).
Write new entries under **[Unreleased]**. The publish script moves them under the new version number when you release.

## [Unreleased]

## [1.0.0] - 2026-11-26

## [0.1.0] - 2026-11-25

- Fixed: **Where Was I: Settings Menu** in the Command Palette failed with "command not found". It now opens the settings menu.
- Smaller download: the extension is bundled into one file with esbuild, and the usage GIF is no longer packaged.
- New releases are published to GitHub Releases, the VS Code Marketplace and Open VSX together.

## [0.0.1] - 2026-06-24

- Initial release: highlights the lines changed in the latest commit of the open file, with preset colors, a "show only yours" filter, a status bar menu and the `Ctrl+Alt+W` toggle.
